# Zun Khet Wai — Portfolio

A lightweight, data-driven portfolio built for GitHub Pages.

## Updating content

Content lives in `data/`. Add or edit entries there instead of editing `index.html`.

- `profile.js` — name, bio, portrait, location
- `research.js` — research interests
- `projects.js` — projects and featured status
- `background.js` — background narrative
- `skills.js` — grouped skills
- `experience.js` — work experience
- `education.js` — education
- `publications.js` — publications
- `links.js` — contact and social links

## Portrait

Put your portrait at `assets/profile/portrait.jpg` and set `image: "assets/profile/portrait.jpg"` in `data/profile.js`.
